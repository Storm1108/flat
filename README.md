# Студия 23,5

Локальный планировщик квартиры на React, TypeScript, Vite, Three.js, React Three Fiber, Drei и Zustand. В браузере можно менять расстановку, измерять расстояния, открывать фасады и проверять пересечения.

## Запуск на macOS

Установите актуальную LTS-версию [Node.js](https://nodejs.org/) (поддерживается Node.js 20.19+, рекомендуется 22 или 24 LTS). Распакуйте архив и откройте в Терминале папку `studio-planner`. Выполните:

```bash
npm install
npm run dev
```

Откройте адрес из вывода Vite, обычно [http://127.0.0.1:5173](http://127.0.0.1:5173). Приложению нужны интернет для первоначальной установки зависимостей и браузер с WebGL 2 для 3D. После установки приложение работает локально, без учётной записи. Проверенный браузер — Chromium. Для работы с планом достаточно SVG.

## Работа с проектом

| Действие | Как выполнить |
| --- | --- |
| Выбрать мебель | Нажмите на предмет в списке, на плане или в 3D. |
| Переставить мебель | Перетащите предмет на плане с шагом 10 мм. Для точной правки введите X, Z, высоту от пола и угол в панели «Свойства». Enter подтверждает значение. |
| Изменить объект | В свойствах доступны габариты, цвет, материал и видимость. У холодильника можно изменить сторону навески. У духовки, СВЧ, тумбы и вытяжки есть подвижные детали. |
| Добавить объект | Кнопка «＋» над списком открывает каталог. |
| Измерить | Включите «Измерить» и укажите две точки. На плане измерение горизонтальное, в 3D — пространственное. |
| Прогуляться | Откройте «Прогулка». Удерживайте экранный джойстик для плавного движения. Сильнее отклоните джойстик, чтобы идти быстрее. На планшете проведите пальцем по сцене, чтобы осмотреться. Нажатие на сцену захватывает мышь, Esc освобождает. WASD и стрелки управляют движением. Столкновения с мебелью и высоту глаз можно изменить через «Вид и свет». |
| Осмотреть интерьер | В «3D-виде» перетаскивание вращает камеру, колесо меняет масштаб. Срез ближних стен, видимость стен и потолка, свет и качество находятся в «Вид и свет». |
| Проверить расстановку | «Проверки» показывает пересечения, подходы к дверям, конфликты кухни и трассу воздуховода. «Размеры» включает размерные линии и расчётные проходы на плане. |
| Уточнить размеры | Откройте «Исходные размеры» и включите редактирование. Координаты воздуховода редактируются в «Вид и свет». |
| Сменить мебель прихожей | В «Варианты» выберите высокий или низкий шкаф для стиральной машины и ширину платяного шкафа, затем нажмите «Применить к прихожей». |
| Сохранить | Текущий проект и варианты сохраняются в браузере. «Экспорт JSON» скачивает текущий проект для переноса или резервной копии. |
| Сделать кадр | «Скачать PNG» сохраняет план или текущий 3D-ракурс. Для более чёткого 3D включите повышенное качество. |

`⌘Z` / `Ctrl+Z` отменяет действие. С Shift восстанавливает. При изменении положения или угла родительского модуля встроенная техника движется вместе с ним. Габариты техники редактируются отдельно.

На планшете разрешение 3D автоматически меняется при просадке частоты кадров. Для стандартного режима включите «Вид и свет» и оставьте «Повышенное качество 3D» выключенным.

## Проверка и сборка

```bash
npm test
npm run build
npm run preview
```

`apartment.json` содержит исходные размеры, расстановку, материалы и трассу. `GEOMETRY.md` объясняет систему координат, источники и расхождения. `IMPLEMENTATION_STATUS.md` фиксирует результаты проверки и ограничения. Модель стен и проверки лежат в `src/model.ts`. Редактор и история изменений разделены между `src/main.tsx` и `src/store.ts`, виды — между `src/plan.tsx`, `src/scene.tsx` и `src/models.tsx`.
